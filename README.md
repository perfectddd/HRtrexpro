# HR Trainer

PWA สำหรับ Chrome บน Android ที่อ่านชีพจรจาก **Amazfit T-Rex Pro** ผ่าน Bluetooth โดยตรง
แล้วแสดงชีพจร, Zone, จับเวลา, รันโปรแกรม Interval/Tabata/สร้างเอง และเก็บประวัติในเครื่อง

## ฟีเจอร์
- **หน้าฝึก**
  - ชีพจรตัวใหญ่ในวงแหวนสี Zone และแถบ 5 Zone
    - สีที่แสดงจะเปลี่ยนเมื่อชีพจรอยู่ใน Zone ใหม่ครบ 2 วินาที จึงไม่กะพริบตอนชีพจรอยู่ตรงขอบ Zone
  - เวลารวม, นับถอยหลังของแต่ละช่วง, แถบความคืบหน้า และบอกช่วงถัดไป
  - **เวลานาฬิกา (⌚):** อ่านจาก T-Rex Pro ทุก 5 นาที และบอกถ้าเวลานาฬิกาช้าหรือเร็วกว่าเครื่องตั้งแต่ 2 วินาที
  - **เริ่มจากนาฬิกา:**
    1. เลือกโหมดออกกำลังกายบนนาฬิกาไว้ก่อน
    2. กด "เริ่มจากนาฬิกา" ในแอป
    3. กดเริ่มบนนาฬิกา แอปจะเริ่มพร้อมกัน
    - นาฬิกาส่งสัญญาณแบบเดียวกันทุกปุ่ม การกดหยุดชั่วคราวหรือจบบนนาฬิกาจึงไม่หยุดแอป
  - แจ้งเตือนด้วยเสียง/สั่น/แฟลช เมื่อนับ 3-2-1, เปลี่ยนช่วง, เปลี่ยน Zone, เกินเป้า, ต่ำกว่าเป้า และนาฬิกาหลุด
  - ปุ่มเปิด-ปิดเสียง
- **สี Zone:** เลือกเองได้ทีละ Zone หรือใช้ชุดสีสำเร็จรูป (นุ่มนวล, คลาสสิก, เอิร์ธโทน)
  - สีเดียวกันใช้กับวงแหวน, พื้นหลัง PiP และกราฟ
- **โปรแกรมฝึก:** สร้าง/แก้/ทำสำเนาได้; ประกอบจาก step และบล็อกทำซ้ำ, ตั้ง Zone เป้าหมายแยกแต่ละ step, step แบบ "จนกว่าจะกดถัดไป"
- **หน้าต่างย่อ**
  - ปุ่มหน้าต่างลอย (Picture-in-Picture) ทับแอปอื่น พื้นหลังเป็นสี Zone และตัวอักษรเลือกสีอ่านง่ายให้อัตโนมัติ
  - เมื่อหน้าต่างสูงน้อยกว่า 400px (แบ่งจอ) จะเปลี่ยนเป็น layout แบบย่อ
- **สรุปและประวัติ:** กราฟชีพจร, เวลาในแต่ละ Zone, export CSV/JSON
- **กู้คืนการฝึก:** ถ้าแอปปิดกลางคัน เปิดใหม่จะมีให้กู้คืนการฝึกที่ค้างอยู่

## เตรียมนาฬิกา (T-Rex Pro ต้องใช้ auth key)
T-Rex Pro ไม่มีโหมด Heart Rate Broadcast แอปจึงยืนยันตัวด้วย **auth key เดิมของนาฬิกา**
แอปจะไม่ตั้ง key ใหม่ จึงไม่กระทบการจับคู่กับ Zepp
ผลการทดสอบอยู่ใน `spike/RESULT.md`

1. **หา auth key:** Zepp → โปรไฟล์ → Settings → About → แตะโลโก้ 10 ครั้ง → Network diagnostics → Share logs
   (ส่งให้ Notify for smartwatch หรือเก็บไฟล์ไว้แล้วค้นหาค่า auth key)
2. ในแอปนี้ ไปที่ ⚙️ **ตั้งค่า → นาฬิกา** แล้ววาง key (hex 32 ตัวอักษร)
   - เปิด crypt flag 0x80 ไว้ (ค่าเริ่มต้น)
   - กดบันทึก
3. ก่อนฝึก **ปิด Bluetooth มือถือ** เพราะนาฬิกาเชื่อมต่อได้ทีละเครื่อง
4. หน้าฝึก → ⌚ → เลือก **Amazfit T-Rex Pro**

ข้อควรระวัง:
- ห้ามรีเซ็ตหรือ unpair นาฬิกา เพราะ key จะเปลี่ยน
- key เก็บไว้ใน IndexedDB ของเครื่องนี้เท่านั้น

## รันบนมือถือผ่าน USB (ไม่ต้องขึ้นเว็บ)
Web Bluetooth ใช้ได้เฉพาะบน HTTPS หรือ `localhost` จึงใช้ `adb reverse` ให้มือถือเปิด `localhost` ของคอมได้

ขั้นตอน:
1. บนคอม รันเซิร์ฟเวอร์
   ```bash
   npm run serve
   ```
2. เปิด USB debugging บนมือถือ เสียบสาย แล้วรัน
   ```bash
   adb reverse tcp:8080 tcp:8080
   ```
3. เปิด Chrome บนมือถือ แล้วเข้า
   - `http://localhost:8080/hr-trainer/` สำหรับแอปจริง
   - `http://localhost:8080/spike/` สำหรับหน้าทดสอบ BLE + PiP
4. เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**

## ทดสอบโดยไม่ใช้นาฬิกา
เปิดหน้าฝึก แล้วกด **Demo** แอปจะสร้างค่าชีพจรจำลองระหว่าง 90–175 bpm

## พัฒนา
```bash
npm test
```
- unit test ใช้ `node --test` (Node 22+) ไม่มี dependency
- โค้ดแอปอยู่ใน `hr-trainer/` เป็น ES modules ล้วน ไม่มีขั้นตอน build
- service worker ใช้แบบ network-first: เมื่อออนไลน์จะได้โค้ดใหม่เสมอ และเมื่อออฟไลน์จะใช้ cache
