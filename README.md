# HR Trainer

PWA สำหรับ Chrome บน Android ที่อ่านชีพจรจาก **Amazfit T-Rex Pro** ผ่าน Bluetooth โดยตรง
แล้วแสดงชีพจร, Zone, จับเวลา, รันโปรแกรม Interval/Tabata/สร้างเอง และเก็บประวัติในเครื่อง

## ฟีเจอร์
- **หน้าฝึก**
  - ชีพจรตัวใหญ่ และพื้นหลังเปลี่ยนสีตาม Zone
  - เวลารวม, นับถอยหลังของแต่ละช่วง และบอกช่วงถัดไป
  - แจ้งเตือนด้วยเสียง/สั่น/แฟลช เมื่อนับ 3-2-1, เปลี่ยนช่วง, เปลี่ยน Zone, เกินเป้า, ต่ำกว่าเป้า และนาฬิกาหลุด
  - ปุ่ม 🔊/🔇 เปิด-ปิดเสียง
- **โปรแกรมฝึก:** สร้าง/แก้/ทำสำเนาได้; ประกอบจาก step และบล็อกทำซ้ำ, ตั้ง Zone เป้าหมายแยกแต่ละ step, step แบบ "จนกว่าจะกดถัดไป"
- **หน้าต่างย่อ**
  - ปุ่ม ⧉ เปิดหน้าต่างลอย (Picture-in-Picture) ทับแอปอื่น
  - เมื่อหน้าต่างสูงน้อยกว่า 400px (แบ่งจอ) จะเปลี่ยนเป็น layout แบบย่อ
- **สรุปและประวัติ:** กราฟชีพจร, เวลาในแต่ละ Zone, export CSV/JSON
- **กู้คืนการฝึก:** ถ้าแอปปิดกลางคัน เปิดใหม่จะมีให้กู้คืนการฝึกที่ค้างอยู่

## เตรียมนาฬิกา
1. เปิดแอป Zepp → โปรไฟล์ → T-Rex Pro → เปิด **Heart rate sharing / broadcast**
   (ชื่อเมนูอาจต่างกันตามเวอร์ชันเฟิร์มแวร์)
2. บนนาฬิกา เริ่มโหมดออกกำลังกาย นาฬิกาจะเริ่มส่งชีพจร
3. ระหว่างฝึกไม่ต้องเปิด Zepp

## รันบนมือถือผ่าน USB (ไม่ต้องขึ้นเว็บ)
Web Bluetooth ใช้ได้เฉพาะบน HTTPS หรือ `localhost` จึงใช้ `adb reverse` ให้มือถือเปิด `localhost` ของคอมได้

ขั้นตอน:
1. บนคอม รันเซิร์ฟเวอร์
   ```bash
   npm run serve
   ```
2. เปิด USB debugging บนมือถือ เสียบสาย แล้วรัน
   ```bash
   adb reverse tcp:8080 tcp:8080
   ```
3. เปิด Chrome บนมือถือ แล้วเข้า
   - `http://localhost:8080/hr-trainer/` สำหรับแอปจริง
   - `http://localhost:8080/spike/` สำหรับหน้าทดสอบ BLE + PiP
4. เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**

## ทดสอบโดยไม่ใช้นาฬิกา
เปิดหน้าฝึก แล้วกด **Demo** แอปจะสร้างค่าชีพจรจำลองระหว่าง 90–175 bpm

## พัฒนา
```bash
npm test
```
- unit test ใช้ `node --test` (Node 22+) ไม่มี dependency
- โค้ดแอปอยู่ใน `hr-trainer/` เป็น ES modules ล้วน ไม่มีขั้นตอน build
- service worker ใช้แบบ network-first: เมื่อออนไลน์จะได้โค้ดใหม่เสมอ และเมื่อออฟไลน์จะใช้ cache
